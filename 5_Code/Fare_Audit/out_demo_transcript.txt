REPRESENTATION REGISTRY (G6GF moveset environments)
------------------------------------------------------------------------------
  BIN   binary string (L1 tape)                env=N  L1  F0 Binary Flag
        moveset: flip, tally
        incapacity: no arithmetic beyond +1/-1 tally (G6GF section 1: the binary environment is irreducibly one-dimensional)
        incapacity: multiplication would require combining two counts into one address, which is not in the moveset
  N64   natural counter, 64-bit unsigned       env=N  L2  F1 Cipher
        moveset: add, sub, mul, div
        incapacity: no values below 0 (subtraction below zero is a domain violation)
        incapacity: negative integers reinterpreted as unsigned magnitudes lose their sign (wrap-around read)
  Z64   signed integer, 64-bit two's complement env=Z  L2  F1 Cipher
        moveset: add, sub, mul, div, cast
        incapacity: no fractions: division with a remainder does not resolve in Z and bends to Q (G6GF section 2, 3/2)
        incapacity: no irrational roots in its moveset
  Q     rational, exact (fractions.Fraction)   env=Q  L3  F2 Address
        moveset: add, sub, mul, div, cast
        incapacity: cannot render irrational roots: sqrt(2) has no exact value here and is approximated (A) or bent toward F/C
        incapacity: no phase: a complex value returning to Q is obfuscated
  F64   IEEE 754 binary64                      env=F  L3  F2 Address
        moveset: add, sub, mul, div, pow, sqrt, abs, cast
        incapacity: cannot represent 1/10 exactly (binary mantissa)
        incapacity: cannot preserve the sign of 0 under abs (-0.0)
        incapacity: lacks exact phase representation (requires the C environment); returning from C applies the [[b]] marker
        incapacity: stuck in transfinite smoothing under nested ^b/sqrt(b): the Apeirogon (G6GF section 4.6)
  D128  IEEE 754 decimal128 (34 significant digits) env=F  L3  F2 Address
        moveset: add, sub, mul, div, cast
        incapacity: only 34 significant decimal digits: a value needing more is rounded
        incapacity: cannot render values with infinite decimal expansions exactly (1/3)
  C128  complex register (pair of binary64)    env=C  L4  F3 NaN (complex register)
        moveset: add, sub, mul, div, conj, abs, phase, sqrt, cast
        incapacity: phase is defined modulo 2*pi: position certainty is lost (Fare Principle)
        incapacity: returning to a real environment destroys the imaginary part (phase obfuscated, [[b]])
  ADDR  memory address (F2 location token)     env=F  L3  F2 Address
        moveset: deref, cast
        incapacity: an address is a container, not a number: reading it as a cipher (Z64) without an explicit cast is a level collision (CTS section 5, Ptr -> Int in C)

FARE LADDER (monograph Ch. III, 3.5; MBP 6.3)
------------------------------------------------------------------------------
  F0  Binary Flag              Flip-Burger (L1)     e.g. tally mark / bit
  F1  Cipher                   Line-Cook (L2)       e.g. integer counter
  F2  Address                  Drink-Runner (L3)    e.g. float location
  F3  NaN (complex register)   Manager (L4)         e.g. complex register
  F4  Set                      Owner (L5)           e.g. matrix / tensor
  F5  Instance                 Tax (L6)             e.g. full ledger
