# Legacy Versions and Intermediary Compilations

This folder contains the historical iterations of *Poetica Mathematica* and the publications that led to it. 

Because the work was developed iteratively over a short period, the distinction between an intermediary draft and a published snapshot is blurred. Some of these files were shared externally, while others were local working compilations. They are all archived here as a record of the work's development.

For the current version, see the **[1_Monograph](../1_Monograph/)** folder.

## Naming Convention

The files are prefixed with a date in the format `YYMMDD_` (e.g., `260225` = February 25, 2026). This ensures the files sort chronologically by default. The titles reflect the versioning and file naming used at the time of creation.
