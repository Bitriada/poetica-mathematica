# Citation Guide

This repository contains multiple citable artifacts. Please cite the specific one you are using. 

For the **living repository** (including past versions, critiques, and legacy archives), you may cite the GitHub URL directly:
> Kovlekov, K. (2026). *Poetica Mathematica* [GitHub Repository]. https://github.com/Bitriada/poetica-mathematica

For **permanent, versioned archives**, please use the Zenodo DOIs below.
